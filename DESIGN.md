# ShareSafe visual direction
Reading this as: a screenshot utility for everyday users and developers, in an
editorial workspace style, ENERGY 2 / RHYTHM 3 / MOTION 1.

- Preserve the supplied off-white, ink, and lime identity. Lime marks actions and
  selected private text; it does not decorate every section.
- Inter remains because small editor controls and mixed screenshot content need
  a legible, quiet interface typeface. Large headings use medium weight.
- Put import and the working sample alongside each other: users understand the
  task and can act without scrolling past a marketing introduction.
- Use a redaction bar as the identity motif: the word 'everywhere' sits on an
  opaque ink rectangle, directly referencing the actual editing operation.
- Use rules and open columns for product explanations, avoiding repeated cards.
- Remove decorative status dots, traffic lights, sparkles, and repeated arrows.
- Retain the explicitly requested fictional sample, three-step instructions and
  product-specific FAQ from the original brief. The sample is visibly labelled.
- Light canvas surroundings support inspecting screenshot edges and transparency.
  Only floating editing controls receive elevation to distinguish them from pixels.
- No new image assets, logos, or illustrations are needed.
- Motion is limited to control feedback; respect reduced motion.
- Readability: body copy uses 16px, controls 14px and supporting labels 13px at
  the default root size. Rem units respect user font preferences; wrapping and
  wider findings give larger text room without changing screenshot pixels.
